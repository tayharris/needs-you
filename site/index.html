How it works

  1. Agents post. A Claude session, a cron job or a CI step says “I need you for this” with one command.
  2. The pill shows it. It floats over everything on your Mac and never takes focus from what you're typing.
  3. It goes away when handled. The sender clears it, or you click Done. Nothing piles up.

Install

Download for Mac

The latest release has NeedsYou-<version>.dmg (open it, drag the app to Applications) and the same app as a .zip. macOS 14 or later.

The app is ad-hoc signed, not notarized, so macOS blocks the first launch. On macOS 15 and later: double-click it, then System Settings → Privacy & Security → Open Anyway. On macOS 14: Right-click the app → Open → Open.

A faint pill appears at the top right. Your Mac is the hub: it holds the alerts, and other machines only need the needs-you command. Then add your other machines: right-click the pill → Settings… → Connect a machine → Create invite → Shell one-liner, and run what it copies on the machine. It looks like this (the Claude Code options are optional):

curl -fsSL <join_url>/install.sh | bash -s -- --yes --claude-hooks user --skill --alerts

Open source

The app, the hub and the sender CLI are on GitHub. Apache-2.0. No cloud, no accounts, no telemetry.
