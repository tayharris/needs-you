For people who run agents, servers and CI

One quiet inbox for “you have to do something.”

Your agents, VMs and CI jobs post when they're blocked on you. A small floating pill on your Mac shows it, and all but disappears when nothing is waiting. No cloud, no accounts, nothing to install.

How it works

Three pieces. The first one is the only thing you install.

  1. 1

    The Mac app is the hub

    NeedsYou.app runs a small built-in hub (HTTP + SQLite) and shows the floating panel. It sits on every Space and display, over full-screen apps, and never steals focus.

  2. 2

    Invite a machine

    Click Invite a machine. Paste the agent prompt into Claude Code, or run the one-line curl command on a server. Each machine gets its own revocable token.

  3. 3

    Agents and servers post

    “I need you for X” is one command. Re-posting the same key updates the item instead of stacking duplicates, and the sender clears it once it's handled.

senders                          your Mac
───────                          ────────
Claude Code ──┐
servers, cron ┼── needs-you ──►  NeedsYou.app
CI jobs ──────┘   CLI or curl    (built-in hub + pill)
                  queues offline       │ optional
                                       ▼
                         always-on hubs (replicate)

Diagram: Claude Code, servers, cron and CI jobs send items with the needs-you CLI or curl to NeedsYou.app on your Mac, which contains the built-in hub and the pill. Senders queue offline. Optional always-on hubs replicate for redundancy.

Quickstart

About five minutes. You need a Mac (macOS 14+) and, for other machines, a Tailscale tailnet.

  1. 1 Open the app

    Build it from the repo (or download a release), move it to Applications and open it. A faint pill appears in a corner: that's the idle state.

    cd mac && scripts/bundle.sh
open dist/NeedsYou.app

  2. 2 Invite a machine

    Click the pill, then Invite a machine. Paste the agent prompt into Claude Code on that machine, or run the one-liner the app shows you:

    curl -fsSL "<invite link from the app>" | bash

  3. 3 Post something

    From the invited machine. The pill springs out, then settles to 1.

    needs-you add --key "personal:$(hostname -s):hello" \
  --context personal --title "Say hi back"
needs-you resolve --key "personal:$(hostname -s):hello"

FAQ

Where does my data go?

Nowhere outside your machines. The hub runs inside the Mac app, or on servers you own, and listens only on loopback or your Tailscale tailnet, never on a public port. There is no cloud service, account or telemetry. Items are meant to hold titles, short text and links; senders are told never to post secrets.

What happens when my Mac is asleep?

Senders keep working. The needs-you CLI writes to a local outbox when no hub answers, exits 0 so your job never fails, and delivers on its next run or needs-you flush. When the Mac wakes, queued items arrive. If you want posts to land immediately while the laptop is closed, add an always-on server hub.

Can I run it without the Mac being the hub?

Yes. Optional always-on hubs (any Linux or macOS box with python3) replicate with each other and the app. Senders try hubs in order and the app fails over, so one machine going down loses nothing.

Will an hourly job spam me?

No. Items are keyed: posting the same key again updates the existing card instead of adding one, and it only re-animates if the title, body or priority changed. There's also a per-sender cap on open items to stop a runaway loop.

What do I need to install on servers?

Nothing. The hub and CLI are single files on the Python 3 standard library (3.9+), which stock Ubuntu and macOS already have. No pip, no brew, no build step.

Does it interrupt what I'm doing?

It's built not to. The panel never takes keyboard focus or activates the app. You can snooze it for 15 minutes to 3 hours, and work and personal items show at different times of day.
